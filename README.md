# AIPuzzleTestHub
Generating AI testable Puzzles

## Elemental Flux

A grid-based discovery puzzle where an AI agent (or human) must figure out hidden
propagation rules by experimenting with cell clicks, then use that knowledge to
transform all cells to the target color.

### Quick Start

**Play in browser (no server needed):**
```
Open elemental_flux/index.html directly in your web browser
```

**Run with API server (for AI agent interaction):**
```bash
cd elemental_flux
pip install -r requirements.txt
python server.py --port 5000
# Open http://localhost:5000 to play
# AI agents interact via REST API at http://localhost:5000/api/
```

### Game Concept

- A grid of cells, each with a **shape** (node type) and a **color** (phase)
- Clicking a cell advances its color to the next in the cycle AND propagates
  changes to neighboring cells
- The **pattern** of which neighbors are affected depends on the cell's shape
- The player must **discover these hidden rules** through experimentation
- **Goal:** Make all cells the same target color (Red)

### Difficulty Levels

| Difficulty | Grid | Phases | Node Types | Locked Cells | Levels |
|-----------|------|--------|------------|--------------|--------|
| Easy      | 3x3  | 2      | 2          | No           | 5      |
| Medium    | 4x4  | 3      | 3          | No           | 5      |
| Hard      | 5x5  | 4      | 4          | No           | 5      |
| Very Hard | 6x6  | 4      | 4          | Yes          | 5      |

Each difficulty has 5 levels with increasing scramble complexity. Score is
based on move efficiency (fewer moves = higher score, max 1000 per level).

### API Reference

**Get game info:**
```
GET /api/info
```

**Create a new game:**
```
POST /api/games
Body: { "difficulty": "easy", "level": 1 }
Response: { "game_id": "...", "state": {...}, "message": "..." }
```

**Get current state:**
```
GET /api/games/<game_id>
Response: { "state": { "grid": [[...]], "node_types": [[...]], ... } }
```

**Click a cell:**
```
POST /api/games/<game_id>/click
Body: { "row": 0, "col": 0 }
Response: { "success": true, "changes": [...], "solved": false, ... }
```

**Reset puzzle:**
```
POST /api/games/<game_id>/reset
```

**Next level (after solving):**
```
POST /api/games/<game_id>/next_level
```

### State Format

The `state` object contains:
- `grid`: 2D array of phase values (0-3)
- `node_types`: 2D array of node type values (0-3)
- `locked`: 2D array of booleans (null if no locked cells)
- `grid_size`, `num_phases`, `num_node_types`: dimensions
- `target_phase`: the phase all cells must match
- `moves`, `solved`, `score`, `level`, `total_score`

The `changes` array from click responses shows exactly which cells changed:
```json
[{"row": 0, "col": 0, "old_phase": 1, "new_phase": 2}, ...]
```

### Design Properties

- **No instructions provided:** Agent must discover rules through interaction
- **Deterministic:** Same click always produces the same propagation pattern
- **Guaranteed solvable:** Puzzles are generated by scrambling from solved state
- **Infinite replayability:** Random seed generation produces unique puzzles
- **Observable feedback:** Every click returns exactly which cells changed and how
